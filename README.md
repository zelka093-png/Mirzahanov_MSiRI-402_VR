# VR-тренажёр работы на станке-пиле

Учебный проект по курсу виртуальной реальности (рубежные контроли № 1 и № 2, 02.11.2026 – 13.11.2026).

Выполнил: **Мирзаханов З.А.**, группа **МСиРИ-402**.

## Версии и пакеты

- `Project_VR`: Unity **6000.0.85f2**, Universal Render Pipeline.
- **SteamVR Plugin 2.8** (OpenVR XR Plugin 1.2.1), TextMeshPro, Newtonsoft Json.
- Ассет **Simple Garage** – здание цеха и верстаки.

## Как запустить

1. Открыть папку `Project_VR` в Unity Hub (версия 6000.0.85f2).
2. Открыть сцену `Assets/Scenes/Тренажёр_пила.unity`.
3. Со шлемом: подключить шлем, запустить SteamVR, нажать **Play**.
4. Без шлема: просто нажать **Play**.

## Управление

**В шлеме:** заготовку берут кнопкой захвата, кнопки пульта нажимают рукой, перемещение – телепорт по полу.

**Без шлема:** W, A, S, D – ходьба, Shift – быстрее, правая кнопка мыши – поворот головы, левая кнопка мыши – нажать кнопку пульта или взять заготовку.

## Сценарий тренажёра

1. **Знакомство** – осмотреть пилу и два верстака, нажать «Далее».
2. **Проверка** – заготовка на верстаке, станок свободен, головка пилы вверху, нажать «Далее».
3. **Взять заготовку** с верстака заготовок (синяя метка).
4. **Установка** – положить заготовку на рабочий стол пилы под диск и отпустить.
5. Ограждение – у пилы нет ограждения, шаг пропускается.
6. **Пуск** – нажать «Пуск».
7. **Резка** – диск крутится, головка опускается на заготовку, проходит вдоль стола и поднимается (6 с).
8. **Снять деталь** и отнести её на верстак продукции (зелёная метка).
9. **Итог** – время и ошибки по видам; «Сначала» – пройти заново.

| Неверное действие | Что происходит |
|---|---|
| «Пуск» без установленной заготовки | отказ, ошибка «Пуск без заготовки» |
| второй «Пуск» во время резки | отказ, ошибка «Повторный пуск» |
| заготовка отпущена мимо станка | ошибка «Неверная установка», можно взять снова |
| деталь отпущена мимо верстака продукции | ошибка «Деталь не на столе продукции» |
| взять заготовку во время резки | заготовка не берётся |
| «Стоп» во время резки | головка поднимается, заготовка остаётся на станке |
| «Сначала» с деталью в руке | просьба сначала положить деталь |

## Скрипты (`Project_VR/Assets/Scripts`)

| Скрипт | Что делает |
|---|---|
| `Training/SawTrainingScenario` | шаги сценария, проверки, резка, ошибки, итог и сброс |
| `Training/BlankGrabber` | захват заготовки рукой SteamVR (вместо Throwable), спрашивает разрешение у сценария |
| `Training/DropZone` | зона станка и зона стола продукции: проверяет, где отпущена деталь |
| `Training/TrainingPanelView` | пульт обучения: список шагов, подсказка, итог |
| `Training/PcButtonClicker` | без шлема нажимает кнопки пультов мышью |
| `Training/PcWalk` | ходьба без шлема, не проходит сквозь стены и станок |
| `MachineController` | вращение диска пилы |
| `CncJsonController` | клиент сервера станка: GET-запрос, JSON, координаты X, Y, Z |
| `ApiStatusPanel` | пульт станка: состояние, координаты, связь, кнопки «Пуск» и «Стоп» |
| `MachineState` | данные станка из JSON: работает или нет, координаты X, Y, Z |
| `WorkpieceSnap.c.cs` | сцена 10.11: заготовка фиксируется в зоне станка |
