Основы классов и объектов
1)Чем класс отличается от объекта?
Класс это шаблон по которому создаются объекты. Объект это экземпляр класса со своими данными

2)Что хранит переменная класса?
Переменная класса хранит данные которые описывают объект. Например, имя, возраст, описание или цвет

3)Что произойдёт при обращении к члену через null-ссылку?
Программа выдаст ошибку, потому что null означает отсутствие ссылки на объект. Обращаться к его полям нельзя

4)Зачем объединять поля и методы в одном классе?
Чтобы данные и действия связанные с ними находились в одном месте. Это делает программу более понятной, удобной и упрощает работу с кодом



Инкапсуляция и конструкторы
1)Зачем скрывать поля класса? 
Чтобы защитить данные и контролировать доступ к ним через специальные методы или свойства

2)Чем свойство отличается от поля?
Поле хранит данные а свойство позволяет получать и изменять их с дополнительной проверкой

3)Что произойдёт, если не объявить ни одного конструктора?
Компилятор автоматически создаст конструктор по умолчанию который позволит создать объект без дополнительных параметров

4)Как конструктор связан с инкапсуляцией?
Конструктор задаёт начальные значения полей объекта и помогает сразу создать его в правильном состоянии

5)Можно ли изменить свойство только для чтения после создания объекта?
Обычно нельзя если свойство доступно только для чтения. Но его значение можно задать внутри конструктора или специальных методов класса
