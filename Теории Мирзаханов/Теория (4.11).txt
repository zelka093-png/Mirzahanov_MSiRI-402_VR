1)Отличие коллайдера от коллизии
Коллайдер (Collider) это компонент объекта который определяет его физические границы и форму. Коллизия (Collision) это само столкновение двух объектов у которых есть коллайдеры

2)Отличие while от do while
while сначала проверяет условие а потом выполняет код. Если условие ложное код не выполнится ни разу
do while сначала выполняет код а потом проверяет условие. Поэтому код выполнится хотя бы один раз

3)Методы Web-запросов.
Основные методы HTTP-запросов:
- GET — получение данных
- POST — отправка новых данных
- PUT — полное обновление данных
- PATCH — частичное обновление данных
- DELETE — удаление данных

4)Когда используется OnCollision и OnTrigger
OnCollision используется для обработки физических столкновений объектов, когда они соприкасаются и взаимодействуют друг с другом
OnTrigger используется для обнаружения попадания объекта в специальную зону. Например, при сборе монет или входе в определённую область

5)Для чего нужен интерфейс Input
Интерфейс Input в Unity нужен для получения действий пользователя: нажатий клавиш, движения мыши, нажатий кнопок мыши и других команд управления игрой. С его помощью можно управлять персонажем и объектами
